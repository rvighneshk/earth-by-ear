How it works

The colorbar is the codebook

Most colour-to-sound tools map colours straight to notes. That is arbitrary: a different palette would sound different, though the data did not change. This project reads the map's own legend first. It works out which number each colour stands for, and only then makes sound. Change the palette and the music stays the same, because the numbers stay the same.

The steps

  1. Find the colorbar in the image and read its colours from low to high.
  2. For every map pixel, find the closest legend colour in a perceptual colour space (CIELAB) and read off the number it stands for. Text, coastlines and grey land match nothing, so they become "no data".
  3. Shrink the result to a grid of a few thousand cells, taking the median of each block.
  4. Turn each number into a sound with the rules below.

The rules

Pitch
Where the value sits on the legend. Higher value, higher note. Notes are snapped to a musical scale so it stays pleasant to listen to. For anomaly maps, "no change" is always the home note.
Tension
How extreme the value is. Mild values sound calm: home note, a fifth, an octave. Extreme values add a tritone, then a minor second, and the sound gets brighter.
Roughness
How much the data changes between neighbouring cells. Smooth regions give a steady tone. Rough regions flutter.
Stereo position
West to east, left to right.
Brightness
Rises with tension and with latitude.
Silence
No data. You hear a soft low thump so you know you reached it.
Duet
An earlier year in the left ear and a later year in the right ear, at the same place. Same note in both ears means nothing changed. A gap between the ears is the change.

The guided tour

The tour is not scripted. It compares two years cell by cell, smooths the difference so single noisy cells cannot win, and visits the biggest increase, the biggest decrease and the most extreme place in the later year. It also visits a place that changed least, but only when that is clearly calmer than the rest. Every caption is built from numbers read from the data. If two years barely differ, it says so instead of inventing a story.

The jukebox score

"Play this visualization" turns every frame into one four-second bar and plays the frames in order, so a whole animation becomes a short piece. The map is read west to east like a playhead in sixteen slices. The average of each slice is the melody note. Calm maps play four steady beats; maps with a wide spread inside a slice fill in every step. Where a slice mixes low and high values, an octave-up sparkle voice joins in. The planet's chord (below) is the pad underneath. Each dataset has its own scale, home note and waveform, so a lightning storm does not sound like a forest.

The planet's chord

A single note describes a single place. To hear a whole map at once, we take every value on it and sort them. The tenth, thirtieth, fiftieth, seventieth and ninetieth percentile values become five notes, using exactly the same pitch rule as everywhere else. That is the map's chord.

  • If the whole distribution warms, the chord climbs.
  • If the map becomes more uneven, the chord spreads wider and starts to flutter.
  • If the extremes get more extreme, tension is added and the sound brightens.

Play every year in order and you hear the planet's chord move, while the map changes on screen. The three values behind each chord (low, middle and high) are shown and read out, so nothing is hidden behind the music.

Limits, stated plainly

  • The sound comes from the image, not the original science file, so it is limited by the picture's colours and size.
  • Most datasets use image brightness as the value. Sea-surface temperature uses the hue of each pixel along the map's blue-to-red ramp, which is a better fit for a rainbow colour map. Both are relative values, not measurements.
  • Globe and camera views are reported by position in the frame, never by invented latitude and longitude; the black sky around a globe is silent.
  • If a legend is banded, only that many distinct values can be recovered.
  • Cyclic colour palettes, where the ends look alike, can confuse the matching.
